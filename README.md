# ต้นแบบทดลอง v2: ซิงค์ iPhone ผ่าน hotspot (ใช้แล้วทิ้ง)

ทดสอบอย่างเดียวว่า iPhone หลายเครื่องที่อยู่ใน hotspot เดียวกัน ส่งข้อมูลหากัน**ตรงในวง**ผ่านหน้าเว็บ (WebRTC) ได้หรือไม่
ไม่มีข้อมูลจริง ไม่ใช่ระบบลงทะเบียน

**v2 เปลี่ยนจาก v1:** เครื่องลูกสแกน QR ของเครื่องแม่**ครั้งเดียว** (QR เล็กลง สแกนด้วยแอปกล้องปกติได้) แล้วเครื่องแม่กด **ยอมรับ**
- ตอนจับคู่ใช้เน็ตส่งข้อความสั้นๆ ผ่านบริการฟรีของ PeerJS (มีแค่ข้อมูลการเชื่อมต่อ ไม่มีข้อมูลชาวไร่)
- ข้อมูลที่ส่งหากันหลังจับคู่ วิ่งตรงในวง hotspot เท่านั้น (ตั้งค่าไม่ให้ออกเน็ต)
- เครื่องลูกที่เคยยอมรับแล้ว ถ้าหลุดหรือรีโหลด จะต่อกลับเองโดยเครื่องแม่ไม่ต้องกดยอมรับซ้ำ

## 1. อัปเดต GitHub Pages

push ไฟล์ทั้งโฟลเดอร์นี้ขึ้น repo เดิม (มีไฟล์ใหม่ `vendor/peerjs.min.js`) แล้วรอ 1–2 นาที
ถ้า Safari ยังแสดงหน้าเก่า (บันทึกบรรทัดแรกไม่มีคำว่า `v2`) ให้ดึงหน้าลงเพื่อรีโหลด

## 2. ทดสอบ (iPhone 2 เครื่องขึ้นไป)

1. **เครื่องแม่:** เปิดข้อมูลมือถือ (จำเป็น ไม่งั้นเปิดฮอตสปอตไม่ได้) → เปิด "ฮอตสปอตส่วนบุคคล"
2. **เครื่องลูก:** ต่อ Wi-Fi ของเครื่องแม่
3. **เครื่องแม่:** เปิดลิงก์ใน Safari → ใส่ชื่อ → **เป็นเครื่องแม่** → อนุญาตกล้อง → ขึ้น QR
4. **เครื่องลูก:** เปิดแอปกล้องปกติ ส่อง QR → แตะลิงก์ที่เด้งขึ้น → ใส่ชื่อ → **เข้าร่วม** → อนุญาตกล้อง
   (หรือเปิดลิงก์เอง แล้วกด "เป็นเครื่องลูก (สแกน QR)" ก็ได้)
5. **เครื่องแม่:** ขึ้นกล่อง "B ขอเข้าร่วม" → กด **ยอมรับ**
6. เครื่องลูกต้องขึ้น **"เข้าร่วมวงแล้ว ✓"** และหัวข้อ "การเชื่อมต่อ" เป็นสีเขียว
   - ดูท้ายบรรทัด ต้องเป็น `host 172.20.10.x ↔ host 172.20.10.x` (แปลว่าวิ่งตรงในวง)
7. พิมพ์ข้อความที่เครื่องหนึ่ง → ต้องขึ้นที่เครื่องอื่น
8. ถ้ามีเครื่องที่ 3 ทำข้อ 4–5 ซ้ำ แล้วส่งข้อความจากลูก B → ต้องไปถึงลูก C

**ทดสอบการหลุด (สำคัญ)**

9. เครื่องลูกล็อกจอ รอ 10 วิ / 1 นาที / 5 นาที แล้วเปิดกลับ → กลับมาเขียวเองไหม ใช้เวลากี่วินาที
10. เครื่องลูกสลับไปแอปอื่นแล้วกลับมา → เหมือนข้อ 9
11. กด **"เปิดกันจอดับ"** แล้ววางไว้ 5 นาที → จอดับเองไหม การเชื่อมต่อยังอยู่ไหม
12. **เครื่องแม่**ล็อกจอแล้วเปิดกลับ → เครื่องลูกเป็นอย่างไร
13. หลังจับคู่แล้ว ให้เครื่องแม่**ปิดข้อมูลมือถือชั่วคราว** (ถ้าฮอตสปอตยังค้างอยู่) → ส่งข้อความยังได้ไหม

## 3. ส่งผลกลับ

ต่อแต่ละเครื่อง กด **"คัดลอก"** ที่หัวข้อบันทึกเหตุการณ์ แล้ววางส่งมา พร้อมบอก:
- รุ่น iPhone และเวอร์ชัน iOS
- ผ่าน/ไม่ผ่านข้อ 6, 7, 8 และบรรทัดเส้นทางในข้อ 6
- ผลข้อ 9–13

## ถ้าไม่ผ่าน

- ค้างที่ "กำลังเชื่อมต่อเครื่องแม่…": เปิดลิงก์ใหม่โดยเติม `?debug=3` ก่อน `#` เช่น `.../spike-lan-sync/?debug=3#join=...` แล้วส่งบันทึกมา
- ค้างที่ "รอเครื่องแม่กดยอมรับ" แต่เครื่องแม่ไม่ขึ้นกล่อง: ดูว่าเครื่องแม่ขึ้น "ตัวจับคู่ออนไลน์" หรือไม่
