# ต้นแบบทดลอง: ซิงค์ iPhone ผ่าน hotspot (ใช้แล้วทิ้ง)

ทดสอบอย่างเดียวว่า iPhone หลายเครื่องที่อยู่ใน hotspot เดียวกัน **โดยไม่มีอินเทอร์เน็ต** ส่งข้อมูลหากันผ่านหน้าเว็บ (WebRTC) ได้หรือไม่
ไม่มีข้อมูลจริง ไม่ใช่ระบบลงทะเบียน

## 1. ขึ้น GitHub Pages (ทำครั้งเดียว)

1. สร้าง repo ใหม่บน GitHub เช่น `spike-lan-sync` (Public ได้ เพราะไม่มีข้อมูลจริง)
2. push ไฟล์ทั้งโฟลเดอร์นี้ (`index.html`, `vendor/`, `README.md`) ขึ้น branch `main`
3. ไปที่ Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/spike-lan-sync/`

## 2. ทดสอบ (iPhone 2 เครื่องขึ้นไป)

**ก่อนตัดเน็ต:** ให้ทุกเครื่องเปิดลิงก์ใน Safari ตอนที่ยังมีเน็ต (หน้าเว็บต้องโหลดค้างไว้ เพราะต้นแบบนี้ยังไม่ได้ทำให้เปิดแบบออฟไลน์)

1. **เครื่องแม่:** ตั้งค่า → ข้อมูลมือถือ → **ปิด** แล้วเปิด "ฮอตสปอตส่วนบุคคล"
2. **เครื่องลูก:** ต่อ Wi-Fi ของเครื่องแม่ (ตอนนี้ทั้งวงไม่มีเน็ต) แล้วกลับมาที่แท็บ Safari เดิม
3. ทุกเครื่อง: ใส่ชื่อเครื่อง (A, B, C) → เลือกบทบาท → **อนุญาตกล้อง**
4. เครื่องแม่กด **"+ เพิ่มเครื่องลูก"** → ขึ้น QR
5. เครื่องลูกกด **"สแกน QR จากเครื่องแม่"** → ส่องจอเครื่องแม่ → เครื่องลูกขึ้น QR คำตอบ
6. เครื่องแม่กด **"สแกน QR คำตอบจากเครื่องลูก"** → ส่องจอเครื่องลูก
7. ดูหัวข้อ "การเชื่อมต่อ" ต้องขึ้นสีเขียว `connected, ช่อง=open, ตอบสนอง xx ms`
8. พิมพ์ข้อความที่เครื่องหนึ่ง → ต้องขึ้นที่เครื่องอื่น
9. ถ้ามีเครื่องที่ 3 ทำข้อ 4–6 ซ้ำ แล้วส่งข้อความจากลูก B → ต้องไปถึงลูก C (เครื่องแม่ส่งต่อให้)

**ทดสอบการหลุด (สำคัญ)**

10. เครื่องลูกกดล็อกจอ รอ 10 วิ / 1 นาที / 5 นาที แล้วเปิดกลับ → ดูว่าการเชื่อมต่อยังเขียวอยู่ไหม
11. เครื่องลูกสลับไปแอปอื่นแล้วกลับมา → ดูเหมือนข้อ 10
12. กด **"เปิดกันจอดับ"** แล้วปล่อยวางไว้ 5 นาที → จอดับเองไหม การเชื่อมต่อยังอยู่ไหม
13. **เครื่องแม่** ล็อกจอแล้วเปิดกลับ → ดูผลที่เครื่องลูก

## 3. ส่งผลกลับ

ต่อแต่ละเครื่อง ให้กด **"คัดลอก"** ที่หัวข้อบันทึกเหตุการณ์ แล้ววางส่งมา พร้อมบอก:
- รุ่น iPhone และเวอร์ชัน iOS
- ผ่าน/ไม่ผ่านข้อ 7, 8, 9
- ผลข้อ 10–13 (หลุดหรือไม่ หลังกี่วินาที)
- สแกน QR ติดยากไหม

## ถ้าไม่ผ่าน ลองเพิ่ม

- เครื่องที่ไม่เชื่อมต่อ: ตั้งค่า → Safari → ขั้นสูง → ฟีเจอร์ → ดูว่ามีอะไรเกี่ยวกับ WebRTC / mDNS ปิดอยู่ไหม แล้วแจ้งมา
- ถ้าสแกนไม่ติด: เพิ่มความสว่างจอเครื่องที่แสดง QR ให้สุด และถือห่าง 15–25 ซม.
